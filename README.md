# ファイル変換ツール

`FileConverter.bat` を実行すると管理者権限で GUI が起動します。Windows とデスクトップ版 Microsoft Excel が必要です（Excel の COM 機能を使ってブックを読み書きします）。

## 使い方

1. 変換の種類を選び、変換元と出力先を指定します。
2. Excel から CSV/TXT にする場合は、ダブルクォートの有無と文字コードを選びます。
3. 「実行」を押します。

Excel からは先頭のワークシートの使用範囲を出力します。CSV はカンマ区切り、TXT はタブ区切りです。テキストから Excel への変換では、CSV はカンマ区切り、TXT はタブ区切りとして読み込み、すべてのセルを文字列形式で保存します。出力できる Excel 形式は XLSX と XLS です。文字コードは UTF-8 BOM あり/なし、Shift-JIS、UTF-16 LE から選べます。テキスト入力は選択した文字コードで読み込みます。

Windows PowerShell 5.1 を使います。Shift-JIS を選ぶ場合は Windows の日本語コードページが利用できる必要があります。
